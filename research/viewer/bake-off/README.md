# Rendering-stack bake-off (YCCO-7)

The criteria were: a textured GLB loads reliably from a URL, about 60 fps with a 5–15 MB model, low build risk, and room for a panorama skybox or splat later. The pick is **three.js inside an Expo DOM component**. It's the only arm that drew a model on the phone, at 60 fps. It adds no native module, because `@expo/dom-webview` is already linked on main. It also keeps every three.js add-on available: GLTFLoader, Draco, Meshopt and, later, splat renderers. Phones went down (DAN-20) before the other two arms finished, so this is a decision on partial evidence.
